# Good Mobile Panel — V3

В этой версии исправлены две главные проблемы предыдущей сборки: визуальный стиль и урезанный интерфейс.

## Структура

**Ровно две папки:**

```text
good-mobile-panel/
├── public/
│   └── index.html
├── static/
│   ├── app.js
│   └── style.css
├── server.js
├── package.json
└── README.md
```

## Что внутри

### Публичная часть
- шапка в стиле референса;
- hero-блок Good Mobile;
- статистические карточки;
- список должностей;
- серверы;
- новости;
- вход в аккаунт;
- ссылки проекта;
- информация о проекте;
- адаптивная верстка.

### Админ-панель
- dashboard;
- администраторы;
- создание/изменение/удаление администраторов;
- системные роли ADMIN/SUPERADMIN;
- должности;
- permissions;
- серверы;
- количество серверов;
- адрес/порт;
- онлайн/игроки/лимиты;
- ссылки;
- новости;
- заявления;
- жалобы;
- настройки публичного сайта;
- статистика;
- журнал аудита;
- поиск;
- статусы;
- приоритеты;
- назначение ответственных;
- JWT + bcrypt;
- SQLite;
- public API.

## Запуск

```bash
npm install
npm start
```

Открыть `http://localhost:3000`.

Демо:
`admin` / `admin12345`

Перед production обязательно заменить `AUTH_SECRET` через переменную окружения и сменить пароль.
