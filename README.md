# Good Mobile Panel

Railway + PostgreSQL. Никакого SQLite. При старте схема создаётся автоматически.

Папки только `public` и `static`.

## Railway
Подключи PostgreSQL к сервису приложения, чтобы Railway передал `DATABASE_URL`.
Также задай `SESSION_SECRET`.

## Первый вход
Если администраторов нет, на странице входа появится «Создать владельца». Пароль от 10 символов и хешируется bcrypt.

## APK
Админка → Настройки → APK игры → загрузка. Файл сохраняется как `public/game.apk`, а `/download/game` отдаёт его скачиванием. Кнопка «Начать играть» по умолчанию ведёт туда.

## Возможности
Администраторы, роли/должности, permissions, серверы, ссылки, новости, заявления, жалобы, статистика, аудит, настройки, юридические страницы, загрузка APK и изображений.
