# Good Mobile Panel — без базы данных

Лёгкая Railway-версия: данные хранятся в `data.json`, файлы сайта и APK — в `public/`.

## Railway

Запуск: `npm start`

Переменные:
- `PORT` — Railway задаёт автоматически
- `SESSION_SECRET` — обязательно задай длинную случайную строку

База данных не нужна.

## Первый запуск
Открой сайт. Если администраторов нет, появится форма создания владельца.

## APK
Админка → Файлы сайта → Загрузить APK. После загрузки `/download/game` скачивает `GoodMobile.apk`, а кнопка «Начать играть» ведёт туда.

## Важно про Railway
Без Volume файловая система Railway не является постоянным хранилищем при пересоздании/новом деплое. Для простого теста это нормально; для постоянных APK/данных позже можно подключить Volume или внешнее хранилище.
