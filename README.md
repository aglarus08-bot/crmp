## Запуск

```bash
npm install
npm start
```

Открыть `http://localhost:3000`.

### Первый запуск

Пароль администратора **не хранится в исходниках и не показывается в интерфейсе**.

```bash
ADMIN_LOGIN=admin ADMIN_PASSWORD="ваш-длинный-пароль" npm start
```

`ADMIN_PASSWORD` — минимум 10 символов. Если база уже содержит пользователей, переменные первого запуска не меняют их пароли.

### APK

SUPERADMIN открывает **Настройки → APK игры**, выбирает `.apk` до 300 MB и загружает его. После загрузки публичная кнопка **«Начать играть»** ведёт на `/download/game` и скачивает APK. Файл хранится непосредственно в `public/game.apk`, отдельной папки `uploads` нет.

Перед production обязательно задайте собственный `AUTH_SECRET`.
