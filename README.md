# Good Mobile

Готовый full-stack шаблон игрового портала в стиле современного RP-проекта.

## Что уже есть

- Good Mobile вместо Wild Russia.
- Тёмная адаптивная главная страница с зелёным акцентным цветом.
- Регистрация и вход пользователей.
- Администратор с ролью `admin`.
- Админ-панель, доступная только администраторам.
- Стартовый админ: **Pitt / danon**.
- CRUD серверов: название, описание, IP:порт, онлайн, максимум, статус, обложка.
- CRUD новостей.
- Загрузка APK прямо из файлового менеджера телефона/ПК.
- Настройка прямой ссылки на APK.
- Управление Telegram, Discord, VK и другими социальными ссылками.
- Управление текстами hero-блока, описанием, футером и юридическими документами.
- Система доната: создание заявок, выбор сервера/способа оплаты, история, статусы.
- Админ может менять статус донатов.
- Система поддержки: тикеты пользователя + ответы администратора.
- FAQ, преимущества проекта, CTA и блок бренда Grand Mobile.
- Кнопка копирования IP.
- SQLite база данных без отдельного сервера БД.
- Загрузка файлов через `multipart/form-data`.
- API построен на Express.

## Запуск

Нужен Node.js 20+.

```bash
npm install
npm start
```

Откройте `http://localhost:3000`.

Для разработки:

```bash
npm run dev
```

## Админка

Откройте `http://localhost:3000/admin.html` после входа.

Стартовые данные:

- Логин: `Pitt`
- Пароль: `danon`

Для продакшена обязательно замените пароль и используйте HTTPS.

## Реальный платёж

В проекте есть полноценная бизнес-логика заявки на донат, история и управление статусами. Поле «Ссылка оплаты» намеренно сделано универсальным: в админке можно указать URL вашего платёжного провайдера. Сам проект не подменяет платёжный шлюз и не хранит данные банковских карт.

Для автоматического подтверждения оплаты подключите webhook выбранного провайдера к таблице `donations`.

## Структура

- `server.js` — API, авторизация, загрузки, база.
- `public/index.html` — публичная страница.
- `public/admin.html` — админ-панель.
- `public/styles.css` — дизайн.
- `public/app.js` — публичный клиент.
- `public/admin.js` — клиент админки.
- `data/good-mobile.sqlite` — создаётся автоматически.

## Важное

Это готовая основа для запуска, а не привязка к конкретному хостингу. Для VPS обычно достаточно:

```bash
npm install
npm start
```

и reverse proxy через Nginx/Caddy.
